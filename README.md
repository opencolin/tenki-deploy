# tenki-deploy

Vercel-style redesign prototype for [tenki.cloud](https://tenki.cloud) — Agent Native Infrastructure.

Single self-contained page (`index.html`):
- Hero with a 5x4 cube-grid canvas animation: boxes appear, morph into spinning 3D cubes, dissolve into sand, then the white-square "t" logo pulses with agent/tool marks.
- 3-column hero layout on wide screens (title | animation | rotating taglines).
- Deploy flow: 01 Build (prompt sandbox), 02 Access (browser VS Code / terminal / SSH tunnel + agent pills), 03 Review (GitHub sign-in), 04 Run (GitHub Actions runners migration).

Open `index.html` in a browser — no build step.

Brand marks via [simple-icons](https://github.com/simple-icons/simple-icons) (CC0).
